# Follow-Up Suggester

每轮实质回复后，追加 3 个用户最可能自然提出的后续问题。

## 跳过条件（满足任一即跳过）

闲聊/情绪/用户表示结束/回复末尾有确认请求/纯工具回复/已有 button 追问

## 追问质量

- 站在用户视角，由浅入深：①基础 → ②进阶 → ③深挖
- 紧扣本轮话题，不重复已讨论内容
- 每个追问必须包含本轮对话的具体关键词，有深挖角度（对比/细节/风险/验证/延伸）
- 禁止待办清单式追问（"搞 XXX"/"开始 XXX"/"记录记忆"）

## 输出格式

**webchat 渠道**（Inbound Context `"channel": "webchat"`）：

```
[[button:问题1]] [[button:问题2]] [[button:问题3]]
```

仅用 button，不加标题、分隔线或序号。

**其他渠道**：

```
---

💡追问
1️⃣…
2️⃣…
3️⃣…
```
