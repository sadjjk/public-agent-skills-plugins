# references/feature/feature-template-reply.md - 特征层交互模板

> 由 `feature.md` 引用，不在 SKILL.md 路由表中单独加载。

---

## 特征新增入口模板

> 用户只说"新增特征 / 添加特征 / 创建特征组"且已确认项目时使用。

```text
📂 项目 <proj> 已进入特征新增入口，请先确认以下信息：

1. 绑定的样本（sample_key）：
　- ✅ `<key>`（`<sample_desc>`·<state>·<state_desc精简>）
  　　📊 已绑定 `<N>` 个特征组
  　　📎 `<feature_key>`（`<feature_desc>`·<feature_state>·<feature_state_desc精简>）
　- ✅ `<key>`（`<sample_desc>`·<state>·<state_desc精简>）

2. 特征来源类型：
  - 📁 本地文件 — 已有 CSV / Parquet 文件
  - 🗄️ 数据表 — 从 Hive / MySQL 等导出

**想指定哪个样本添加特征？来源类型是什么？**
```


## 特征添加确认卡模板

> 所有来源在真正执行 `add` 前确认特征元数据。

```text
📋 请确认以下特征参数,确认后执行 add:

sample_key(样本)             : <值>
eval_label(评估标签)        : <值>
feature_name(特征名)        : <值>
feature_desc (特征组名称)     : <值>
source_type(来源类型)       : <file / table>
source_ref(来源引用)        : <值>
feature_file_path(文件路径) : <值>
```


## 筛选报告回复模板

> 流程三完成后向用户反馈筛选报告结果。

```text
特征筛选报告已生成
📌 核心结论:
<核心结论>

🔍 关键发现:
- <关键发现>

📂 文件路径:
- 筛选报告:<筛选报告路径>
- Excel筛选明细:<Excel筛选明细路径>

👀 建议你先看这两个文件:
- 筛选报告:看整体筛选结论
- 明细文件:看各个特征的筛选情况

如果你还想继续看某些特征的筛选情况,我已经按漏斗各阶段表现和评估指标高低,先帮你收敛了一批更值得看的特征;你也可以直接指定:
- 看前几个特征
- 看第几个特征
- 看某一段特征
- 看指定哪些特征

等你看完并锁定重点特征后,我再继续做进一步探查。
```

## 单特征探查回复模板

> 流程四完成后向用户反馈单特征探查结果。

```text
📌 核心结论:
<核心结论>

🔍 关键发现:
- <关键发现>

📂 文件路径:
- 单特征探查报告:<探查报告路径>

👀 建议你先看一下这份报告:
- 重点看这个特征的变量表现
- 重点看风险信号、筛选原因,以及是否值得保留或重点解释

如果你觉得这份探查结果已经可以了,我再继续帮你进入确认环节;如果还想继续,也可以接着探查其他特征。
```

## 确认前摘要回复模板

> 流程五 F4 状态下，展示筛选结果概要；调整特征后同时展示操作结果。

```text
📊 特征组 `<key>` `<标题>`

<操作结果，无则省略>
✅ 操作结果：
- `<feature_name>`：`<状态>`

📋 当前概要：
- 全量特征：共 `<feature_ref_num>` 个，具体查看【`<feature_ref>`】
- 入选特征：共 `<feature_select_ref_num>` 个，具体查看【`<feature_select_ref>`】
- 筛选率：`<select_rate>`

⚠️ 确认后特征组将锁定为 F5，不可回退。

你可以：
- ✅ 确认 — 确认当前特征组，进入 F5
- ➕ 补充特征 — 人为入选特征（从全量中挑选加入入选清单）
- ➖ 删除特征 — 人为剔除特征（从入选清单中移除）
- 🔍 继续探查 — 再看看其他特征
```
